## 实际代码入口

- `web/app.js` 的 `renderMarket` 与三部分渲染函数；`web/index.html` 导航；`web/style.css` 自适应布局。
- `GET /api/v2/workspace/market-panorama`：在 `workspace_web.py` 鉴权后调用 `stage2/market_panorama.py`，仅查询已保存数据。
- `stage2/macro_refresh.py`：唯一 worker 中每15分钟分别采集开盘啦018、072，每次tick至多一个请求，先保存再展示。
- `stage2/market_turnover.py`：唯一 worker 中采集 TickFlow 上证A股指数000002.SH、深证A股指数399107.SZ，复用现有凭据及交易日历。
- `stage2/http_json.py`：GET/POST共享总截止时间、响应大小限制、不跳转和不自动重试的原生HTTP传输。

## 展示与计算

市场背景复用备份圆环、涨跌/涨跌停子集图例及占比。018提供上涨、下跌、涨停、跌停家数；原合同没有平盘和源观测时间，分别显示缺值和采集时间，不通过证券总数或本地时钟推算。

市场成交保留09:35、10:35、11:35、13:05、14:05、15:00六个时点。沪深A股两指数原始成交额均为元，后台使用Decimal计算，页面以亿元展示。分钟累计要求从09:30开盘点开始连续完整，下午从13:01继续；某一分钟缺失仅影响使用该分钟的时点。11:35展示截至11:30的上午累计额，并保留11:30源时间；旧归档缺少该时点时，从已有raw_response本地派生，页面读取及worker完整性检查共用，避免重复采集。15:00使用已收盘日线，保留其源日期标签。柱图展示最近五个交易日，均值比较使用当前日之前五个交易日；任何基线缺失时相应比较留空。不会用ETF成交额替代沪深A股成交额。

全球指数使用072已存数据，按全球股指、股指期货、全球商品、汇率分组为红涨绿跌卡片，可展开详情。源观测时间与后台采集时间分别保存。

## 采集与发布配置

沿用既有 `ENABLE_OFFICIAL_COLLECTION` 开关、`APP_KAIPANLA_CAPTURES`、`APP_TICKFLOW_CONFIG` 与 `APP_CALENDAR_FILE`。生产发布前需要在现有开盘啦私有请求目录安装018配置，072与041保留。密钥与请求URL不进入Git。

成交采集每tick至多一个8秒内物理请求，跨重启通过`collection_requests`记账。当日分钟采集至少间隔900秒；历史最多六个日期，每日期最多两次，第二次等待900秒，每日历史总预算12；日线范围每日最多一次。已经完整的历史数据直接复用，失败日期不阻塞其他日期。新代码复用现有通用持久表，无新增数据库迁移。
